**Neon Harbor Nights** — an original top-down open-world crime game set in Port Solano, a sun-soaked coastal city of pastel towers, palm-lined avenues and one long beach. You are Rook, a courier who works for fixer Marisol Vega: run her errands (package pickups, borrowed wheels, checkpoint sprints, a hot night laying low at the Plaza Fountain), bank the cash, and grow the legend. The whole city is open from the first minute: walk it, or take any car you can reach — traffic to carjack, parked cars to borrow, even a police cruiser if you are feeling bold. Mischief raises your wanted stars; Port Solano police give chase and will bust you if they hold you still, so break their line of sight and let the heat cool. Punch passers-by for their wallets, hunt the cash bundles hidden around the landmarks, wreck cars, get wrecked — then run it back. Five story errands give way to endless procedurally-assigned work, with your money, wanted level, health and mission state on a full HUD with a live minimap, and your run saved between visits.

Controls: **W A S D / arrow keys** move and drive · **E** enter or leave a car · **Shift** sprint · **Space** handbrake · **J** punch · **P** pause · **M** sound on/off · **R** restart a finished run. Built with plain canvas and the Web Audio API — no libraries, no assets, no network: every sprite is drawn in code and every sound is synthesised.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. (Any static file server pointed at `game/` works just as well.)
